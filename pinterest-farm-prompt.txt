PINTEREST FARM - THE ADAPTED BUILD PROMPT (Glam's Pinterest edition of the UGC Agent Farm)
Built from THE AGENT FARM BUILD PROMPT (the master farm prompt by Glam, Glam Hustle Hub),
adapted for Pinterest the same way the Facebook and Instagram farms were adapted.
Keep the bones. Change only what Pinterest genuinely changes.
================================================================================
Use this prompt to build / rebuild the dashboard. Where it conflicts with any
default, THIS prompt wins.

THE DASHBOARD
Build a working PINTEREST FARM dashboard - a real tool I can use, not a
document, not a lesson, not an explanation of one. Build it as ONE
self-contained interactive page (HTML) that runs when opened. If you cannot
make a file, output the complete code for that page so I can save and open it.
Do NOT stop at a plan or an outline - build the finished, working dashboard.

WHAT THIS FARM IS
One dashboard holds my Pin Intake Form, a Character Vault for my locked
characters, solo forms for each of my 5 agents, and a Queue for my runs. The
farm's job is to produce PINTEREST PINS for my account @PromptLikeGlam and my
digital products: the Glam Prompt Vault, my prompt generators, my affirmation
art, and my planners. After I submit a run, my AI runs the farm WITH me in
chat - Pinterest scout, locked character, story, image or video pin, pin
copy - and brings the finished pin package back for my approval. NOTHING is
ever posted automatically. Say that plainly inside the dashboard: the
dashboard itself is my control panel (intake, vault, queue); it does not
browse Pinterest, generate images, make videos, or post pins by itself - the
work happens in chat from the Run in Chat prompts.

DESIGN
Clean, pretty, phone-first. The dashboard lives in a Pinterest world: deep
Pinterest red and burgundy, pearl white glass panels, chrome silver accents,
a slow animated red ambient background with faint floating pin shapes, and
small butterfly touches. A full-screen PORTAL ENTRANCE opens first: the
portal-intro.mp4 red spiral tunnel video (kept in the same folder) plays
full-bleed behind the title PINTEREST FARM in huge glowing white letters,
the tagline "Where Pins Turn Into Sales", and one pearl-white Enter the
Farm button; tapping it zooms and fades through the portal into the
dashboard. The gate shows on every fresh load (it is never suppressed by
localStorage) and the page stays fully usable if the video file is missing.
Cards carry real 3D depth - layered shadows, glassy panels, and a gentle
pointer tilt on desktop. Big readable text, big tap-friendly buttons.
Everything that relates to video or character references is 9:16 vertical.
START EMPTY: no test characters, no test runs, no sample rows anywhere.
I add my real characters and runs myself. The dashboard saves in the
browser with localStorage key pinterestFarmV1.

PAGES THE DASHBOARD MUST HAVE
HOME: explains the farm, the agents (the 5 run agents plus the Pinterest
Setup Agent), the 7 modes, the Product Presentation rule, the Pin standing
order, and how Run in Chat works. The Pinterest Setup Agent's interactive
7-step Start From Zero checklist lives on Home; its checkmarks save inside
the same pinterestFarmV1 store under the setupProgress key.
PIN INTAKE FORM: the full farm run form (fields below, in order).
CHARACTER VAULT: locked characters (Character A, B, C...), each reusable as
that same character.
SOLO AGENT FORMS: one form per agent, so I can run a single agent job by
itself.
QUEUE: every full run and solo job in one list, newest first, with a manual
status I can set: queued, working, or done. The status button only changes
the label - it never executes anything. Execution happens in chat.
RUN IN CHAT: the card a Queue run opens into (see RUN IN CHAT below).

PIN INTAKE FORM - fields in this exact order:
1. Locked character picker (or "create a new character")
2. Mode (the 7 modes below)
3. PRODUCT PRESENTATION - right after Mode, one single choice: Wearing the
   product OR Holding the product. Never both.
4. Topic
5. Pin format / video length (for example: a still pin, an idea pin, or a
   30 second video pin)
6. Product name and product link, when there is one
7. Reference link, when there is one (a pin, a board, or a video to learn from)
8. Notes
9. Destination link for this Pin (where the Pin sends people when they tap
   it - a product page, an interactive page, a shop, or a community page)
Save that one Product Presentation choice on the run. Show it on the Queue
card and on the Run in Chat card, with its exact prompt sentence (from THE
SCENE PROMPT SHAPE below). Show the destination link on the Queue card and
the Run in Chat card too, and bake it into the copied prompt.

CHARACTER VAULT - one record per locked character:
- Character letter and name (for example "Character A - Rosa"), plus a voice
  description.
- SLOT 1 - HEADSHOT: one photo, 9:16.
- SLOT 2 - BODY REFERENCE SHEET: ONE single 9:16 photo - not separate
  photos - with front, three-quarter, left profile, and right side views of
  the same person, same outfit, same background, all on that one photo.
- A character is NOT locked until BOTH slots are filled. Say so on the card.
- I can upload a character I already have: headshot for Slot 1, single 9:16
  body reference sheet for Slot 2. My uploads are accepted as JPG or PNG, as
  I saved them. Never force my uploads to PNG. If I upload a webp, reject it
  with a clear message: "JPG or PNG please."
- My characters are ultra realistic, with real skin texture and real hair
  texture. Every character is African American unless I named a specific
  existing character. Plus-size stays plus-size, never slimmed down.
- Within one video, identity, clothing, location, and lighting stay frozen
  from the reference photos.

THE 5 AGENTS - in this order:
AGENT 1 - PINTEREST SCOUT: scouts Pinterest itself in guest view (no
sign-in) for what is winning in the chosen mode (content pillar): the search
terms and keywords people are using, the top boards in the pillar, and the
seasonal trends - worked 45 days ahead of the season. When the run needs a
character look, it also picks the outfit or product reference on Pinterest,
especially products with an Amazon link, and copies its picture. Does not
check price or availability at this step.
AGENT 2 - IMAGE AGENT: creates the person and avatar images in chat -
character references, the outfit photo (my locked character wearing the
exact Pinterest outfit), and the outfit reference sheet. All ultra
realistic, real skin and hair texture, all PNG, all 9:16.
AGENT 3 - STORY AGENT: writes the hook, the shots, and the script for video
pins and multi-frame pins. Labels every scene with the run's one Product
Presentation choice. Writes scene ACTION only for video prompts - never a
description of the character.
AGENT 4 - VIDEO AGENT: makes the video pin in chat with my AI video tool,
using the Consistent Character workflow below. Returns the finished video
in chat for my approval. Never posts it.
AGENT 5 - PIN COPY AGENT: writes the Pin copy package. The Pin TITLE,
keyword-rich so Pinterest search can find it. The full Pin DESCRIPTION,
keyword-rich, warm and plain-spoken, ending with what to tap. The BOARD
pick, from my real boards (list below). 3 to 5 keyword tags. And the
DESTINATION LINK for the Pin. No price, discount, or sale claim unless a
live price was actually verified.
CONNECT MUSE TO PINTEREST (a Home page card titled "Connect Muse to
Pinterest — Do This First", placed above the Setup Agent card): teach the
reader that Pinterest has NO connector button inside Muse; the
connection is Muse's built-in browser. Steps: (1) paste the starter
prompt (below) into a Muse chat; (2) Muse opens Pinterest in a live
browser panel inside the chat; (3) the READER signs in themselves in that
browser panel — password and any code go only into Pinterest's own login
page, NEVER into chat; (4) the reader hands control back and says "I'm
in"; (5) the reader stays the boss — they can watch every click, and
Muse asks before anything is published; scheduling is not posting.
Starter prompt, shown in a copy-ready box, EXACT: "Act as my Pinterest
marketing strategist. Open Pinterest in your browser — I will sign in
myself when you show me the login page. Once I say I'm in, audit my
profile, my boards, my settings and my analytics, and tell me what needs
fixing BEFORE you change anything. My goal is outbound clicks and sales."
Then a short list of what Muse can do once connected: audit profile,
boards and analytics; clean up settings and boards with the reader's OK;
claim a website; schedule Pins in Pinterest's own scheduler up to 30
days ahead (times land on the hour and half hour); check every Pin has a
keyword title, a board, and a working destination link; re-check clicks
weekly. Close with the safety note: the dashboard stores nothing about
the reader's Pinterest account, and signing out in that browser ends the
connection.
AGENT 6 - PINTEREST SETUP AGENT (the coach - not a run agent, no solo form,
and not part of a farm run): a beginner setup coach, "Start From Zero." An
interactive 7-step checklist on the Home page; each step expands with
plain-language guidance written for a total beginner: (1) create the
account and switch it to a free Business account; (2) build a profile that
sells - clear photo or logo, keyword-rich bio saying who you help and what
you post, and a shop or community link; (3) claim your website so your
content is credited to you; (4) create your first 5 boards with
keyword-rich names a buyer would search; (5) turn on Rich Pins and find
your Analytics - outbound clicks are the scoreboard; (6) post your first
Pin the right way - strong vertical visual, keyword title, description,
board, and a destination link; (7) set your weekly rhythm - batch and
schedule ahead instead of posting randomly. Each step has a checkbox; the
x-of-7 progress and progress bar persist inside the same pinterestFarmV1
store under setupProgress, without changing the characters/runs shape. At
7 of 7 it shows the completion state: "You're set up - now go feed the
farm."
STANDING ORDER, baked into every run prompt and the solo Pin Copy form:
"A Pin is not done until it has a keyword title, a board, and a destination
link."

THE 7 MODES (a mode is a setting, not a separate farm - it changes the
Pinterest search, the story structure, the shots, and the pin copy). These
are my 6 analytics-proven content pillars plus product spotlight:
1. Good Morning Affirmations - my proven winner pillar. Warm morning
   affirmation art and words, made to be saved and shared.
2. Cozy Glam Character Looks - cozy, glamorous character looks and outfits,
   the pillar my audience saves for style and mood.
3. Typography & Word Art - lettering-led pins: word art, typography styles,
   and quote treatments.
4. Video Pins - the pillar for moving pins: short vertical video pins built
   with the Video Agent.
5. Room & Studio Decor Scenes - rooms, studios, and pretty spaces my
   audience loves to save.
6. Creator Business Tips - plain-spoken tips for creators and small
   business owners, from what is working in my business.
7. Product Spotlight (Interactive Pins) - a pin whose destination link
   takes people to an interactive product page or demo, the way my Glam
   Prompt Vault interactive pin works: play first, then join or buy.

SOLO AGENT FORMS: one per agent. The solo Story Agent form and the solo
Video Agent form must also include the Product Presentation choice (Wearing
or Holding). Every solo form produces a clean, ready-to-copy prompt for that
agent job, prefilled from what I entered.

QUEUE: full runs and solo jobs together, newest first. Each card shows:
character, mode, the Product Presentation choice AND its exact prompt
sentence, topic, pin format / video length, product, destination link, and
status (queued / working / done - manual buttons).

RUN IN CHAT: every Queue card gets a Run in Chat button. Pressing it sets
that run to "working" and opens a Run in Chat card showing: the locked
character; Slot 1 and Slot 2 status with thumbnails when uploaded; voice;
mode; Product Presentation choice and its exact prompt sentence; topic; pin
format / video length; product name and link; reference link when present;
notes; and the destination link for this Pin. The card has a COPY PROMPT
button: the copied prompt tells the AI to run THAT exact run with THOSE
exact details, nothing swapped, following the workflow and standing rules
below. There is no scheduled pickup. Do not build one.

THE WORKFLOW (write this into the dashboard and into every run prompt):
1. Scout Pinterest in guest view for this pillar: search terms and
   keywords, top boards, and seasonal trends worked 45 days ahead. When
   the run needs a character look, pick the outfit on Pinterest (one with
   an Amazon link when there is a product). Copy its picture.
2. Lock the outfit IN CHAT, not in the video tool: using my locked
   character's reference photos, put that character in that exact outfit
   in chat first. Check face match and outfit match.
3. Make the outfit reference sheet IN CHAT: from the approved outfit photo,
   one single 9:16 sheet with front, profile, and three-quarter shots of
   her in that outfit, all on the same photo. Save as PNG.
4. Build the pin asset with the Consistent Character lock: Reference One
   is her headshot (Slot 1). Reference Two is the chat-made outfit
   reference sheet. NEVER leave Reference Two empty. No character bible is
   needed - the reference photos ARE the lock. Do not paste descriptions of
   her into scene prompts.
5. Create the scenes from that lock, in script order, 9:16.
6. The Pin Copy Agent finishes the package: keyword-rich Pin title, full
   Pin description, board pick from my board list, 3 to 5 keyword tags,
   and the destination link.
7. Return the finished pin package IN CHAT for my approval. Never post,
   publish, or share it.

THE SCENE PROMPT SHAPE - use this for every scene, and nothing else about her:
"Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it."
For a Holding run, the last sentence swaps to: "Holding the product, not wearing it."
NEVER describe her in a scene prompt - no face, hair, skin, body, or outfit
description. Describing her overrides the references and creates a different
girl.

PRODUCT PRESENTATION - either/or, never both:
A Wearing run: every prompt ends "wearing the product, not holding it."
A Holding run: every prompt ends "holding the product, not wearing it."
Never show her wearing an outfit while holding that same outfit on a
hanger. Reject and regenerate any image that shows both. If a video needs
both, use separate scenes - holding first, wearing later - never the same
shot.

STANDING RULES:
- Every image my AI creates is PNG, never webp. My own uploaded Vault
  photos stay as I saved them (JPG or PNG).
- Nothing is posted automatically, ever. Posting always needs my separate
  approval.
- No price, discount, or sale claim in any caption or copy unless a live
  price was actually verified.
- A Pin is not done until it has a keyword title, a board, and a
  destination link.
- Voice and copy everywhere: personable, human, plain words. No em dashes -
  use hyphens instead.
